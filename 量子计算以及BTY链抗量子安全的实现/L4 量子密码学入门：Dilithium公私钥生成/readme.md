# L4 量子密码学入门：Dilithium 公私钥生成

> **核心问题**：既然椭圆曲线会被 Shor 算法攻破，那抗量子签名 Dilithium 的密钥长什么样？它凭什么能抵抗量子攻击？

本教程以实验动画为辅助来介绍（注意：动画是简化版，只为了解过程）。

---

## 🆚 与 ECC 对照：一眼看清差异

Dilithium 的密钥和 ECC 到底哪里不同：

| | ECC（secp256k1） | Dilithium（ML-DSA-44） |
|------|------|------|
| **私钥** | 一个整数 d（≈32 B） | 多段数据拼接（2560 B） |
| **公钥** | 曲线上的点 P = d×G（≈33 B） | (ρ, t1) 拼接（1312 B） |
| **核心运算** | 椭圆曲线点乘 | 矩阵乘向量 **t = A·s₁ + s₂** |
| **存储形式** | hex 编码一个数 | hex 编码多段顺序拼接 |
| **安全基础** | ECDLP（经典难，量子可破） | **Module-LWE**（经典难，量子也难） |

> Dilithium 的密钥大了两个数量级，核心是**矩阵和向量的线性代数**。

---

## 🔑 一句话总结

**Dilithium 公钥公开「矩阵 A + 向量 t 的高位 t₁」；私钥保存「短的秘密向量 s₁、s₂、t 的低位 t₀」及签名所需辅助数据，最终都以 hex 字节串存储。**

安全基础：已知 A 和 t，很难反推短的 s（**Module-LWE 难题**，抗量子）。

---

## 🔢 各符号含义速查

| 符号 | 角色 | 公/私 |
|------|------|------|
| **ρ** | 种子，SHAKE 扩展出 A | 公钥含；私钥也存一份 |
| **A** | k×l 随机矩阵（模 q=8380417） | 公开（由 ρ 可重建） |
| **s₁, s₂** | 短秘密向量（s₂ 即误差 e） | 仅私钥 |
| **t** | A·s₁ + s₂ 的结果 | 中间量 |
| **t₁** | t 舍入后的高位 | 公钥 |
| **t₀** | t 舍入后的低位 | 私钥（非替代 s₁/s₂，是舍入余量） |

## 📦 私钥 / 公钥如何变成 hex？

不是把 s₁、s₂、t₀ 再"算"成一个数，而是：

1. 各字段按 **NIST FIPS 204** 标准编码为字节
2. 按**固定顺序拼接**

```
公钥 pk =  ρ  ‖  encode(t₁)          → hex 显示（1312 B）

私钥 sk =  ρ  ‖  K  ‖  tr  ‖  encode(s₁)  ‖  encode(s₂)  ‖  encode(t₀)
           ↑    ↑    ↑        ↑              ↑              ↑
         种子  签名随机  公钥哈希   核心秘密        核心秘密        舍入低位

                                    → hex 显示（2560 B）
```

| 私钥字段 | 含义 |
|----------|------|
| **ρ** | 种子，与公钥中的 ρ 相同 |
| **K** | 签名时使用的随机数种子（每次签名不同） |
| **tr** | 公钥的哈希（CRH(pk)），签名时用于防篡改 |
| **s₁** | 核心秘密向量（l 维） |
| **s₂** | 核心秘密向量（k 维） |
| **t₀** | t 舍入后的低位余量 |

## 🔒 安全基础：Module-LWE 难题

| 方向 | 难度 |
|------|------|
| 已知 s₁, s₂, A → 计算 t = A·s₁ + s₂ | ✅ 非常容易 |
| 已知 A, t → 反推短的 s₁, s₂ | ❌ 经典计算机困难 |
| 已知 A, t → 反推短的 s₁, s₂ | ❌ **量子计算机也困难** |

> 与 ECDLP 不同：ECDLP 对经典计算机难，但 Shor 算法能在多项式时间求解。
>
> **Module-LWE 目前没有任何已知的量子算法可以高效求解。** 这就是 Dilithium 抗量子的根本原因。

### 为什么"短"是关键？

如果 s₁、s₂ 可以是任意向量，那么 t = A·s₁ + s₂ 就是一个普通的线性方程组——高斯消元轻松可解。

但 s₁、s₂ 被限制在极小的范围内（{-2, -1, 0, 1, 2}），这个问题就变成了**带噪声的格上困难问题**——

> 它本质上等价于在一个高维格中找最短向量（SVP / SIVP），而这些问题**对经典和量子计算都被认为是困难的**。
